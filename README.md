## Topic

This project introduces the fundamentals of geospatial visualization in R.

Topics covered:

- Geospatial Data
- Vector and Raster Data
- Spatial Layers
- Coordinate Reference Systems
- Dataset Inspection
- Mapping Workflows
- Spatial Filtering
- Decision-Making Applications
